## Featured Projects

### thereMINI: Wearable Theremin
Recognized as the winner of Best Use of FREE-WILi at SpartaHack X, this wearable device converts hand gestures into musical data using specialized sensors. This project demonstrates my ability to integrate hardware with real-time software processing.

### Brave Frontier Exodus
This is a community-driven initiative focused on reviving an online game that was shut down in 2022. My contribution involves editing and maintaining the project to restore gameplay functionality and create a single player offline experience of the original online server based role-playing game.

### ViteReaction
A short and sweet CookieClicker inspired web game. This project was my experimentation with a modular development environment, focusing on performance and modular code structure for a web design course. 

### Digital Signal Processing and Synthesis
I developed a custom pipe organ synthesizer in C++ that uses low-frequency oscillators to implement vibrato and amplitude modulation. This project represents my interest in the technical implementation of digital audio and instrument programming.
